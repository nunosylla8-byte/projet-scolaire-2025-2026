# Gestion Scolaire - École 221

Application web de gestion scolaire développée en PHP procédural pour l'École Supérieure Professionnelle 221 (projet du second semestre, L1, 2025-2026).

Elle permet au secrétariat de gérer les filières, les niveaux, les classes et les étudiants, et d'afficher un tableau de bord et des statistiques.

## Technologies

HTML5, CSS3, Tailwind CSS, PHP procédural, tableaux associatifs, sessions, formulaires, GET et POST, Git et GitHub.

Les données sont conservées dans la session PHP (pas de base de données dans cette première version).

## Lancer le projet

1. Installer PHP.
2. Ouvrir un terminal dans le dossier du projet.
3. Lancer : `php -S localhost:8000`
4. Ouvrir http://localhost:8000/Tableaudebord.php dans le navigateur.

## Pages

| Fichier | Rôle |
|---|---|
| Tableaudebord.php | Tableau de bord |
| Filieres.php | Gestion des filières |
| Niveaux.php | Gestion des niveaux |
| Classes.php | Gestion des classes |
| Etudiants.php | Gestion des étudiants |
| Statistique.php | Statistiques |
| ensemble.php | Session, données de départ et fonctions |
| sidebar.php, ui.php | Menu latéral et éléments d'interface |
